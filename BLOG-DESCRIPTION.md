# Blk Canvas - Responsive Images: Blog Spotlight

Blk Canvas - Responsive Images is the kind of plugin you can boast about in a performance-focused blog. In a few clicks, it swaps WordPress thumbnails and image blocks for modern <picture> markup that serves perfectly sized files to every visitor. Pair the intuitive settings page with your existing media sizes, and you get sharper visuals, lighter pages, and happier readers on any device.
